# SupportDesk Pro

## Objetivo

O SupportDesk Pro é um sistema web para gerenciamento de chamados de suporte técnico.

O objetivo é permitir que empresas registrem, acompanhem e resolvam solicitações de suporte de maneira organizada.

---
